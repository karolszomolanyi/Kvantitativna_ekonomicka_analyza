# Kvantitativna_ekonomicka_analyza
Učebnica slúži študentom ekonomických odborov. Jej obsah zodpovedá nasledovným tematickým častiam: teória firmy, teória spotrebiteľa, teória všeobecnej rovnováhy, teória rastu, teória hospodárskeho cyklu a monetárna teória.

Učebnica: [Kvantitatívna ekonomická analýza](https://karolszomolanyi.github.io/Kvantitativna_ekonomicka_analyza)
