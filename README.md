# Kvantitativna_ekonomicka_analyza
Učebnica slúži študentom ekonomických odborov a predpokladá stredoškolské znalosti matematiky doplnené o aparát predstavený v úvodnej časti (Matematický aparát). Jej obsah zodpovedá nasledovným tematickým častiam: teória firmy, teória spotrebiteľa, teória všeobecnej rovnováhy, teória rastu, teória hospodárskeho cyklu a monetárna teória.
